# リアル英会話
学校では習わない、リアルな英語表現やフレーズをシェア・蓄積できるWebアプリケーションです。

## できること

- ログインなしで、フレーズ一覧を見る
- ユーザー登録とログイン、ログアウト
- マイページで、自分のフレーズを追加・編集・削除する

## 技術

- Java 17
- Spring Boot 4.1.1
- Thymeleaf
- Spring Data JPA
- MySQL
